# Phantom — reconstruction traced from the supplied sheet

Open **Phantom_Traced.blend**. The scene contains separate body shells, armor plates, joints, face plates, two shoulder cannons and paired outer-forearm blades.

The front outline sets the width and height of each body component. The side profile sets its depth. Rear armor uses the rear image. The original sheet and aligned reference images are packed into the Blender file; enable the **REFERENCE** collection to see them.

The renders use plain materials. Optional original-image color projection is available in the materials through **Original image influence** (0 is plain color, 1 is the supplied image). It is off by default because the source contains lighting and some inconsistencies between views. Fine surface details remain simpler than in the supplied images.

**Views:** front, side, rear, three-quarter, face, hand/blade, and clay. The clay image shows the geometry without material colors.

The paired blades follow the earlier requested weapon arrangement. The source sheet itself shows a rifle on the other arm.

This is an editable reconstruction from the images, not a scan or an exact reproduction of every detail. Previous model versions have been preserved.
